# Y

- URL: https://puzzlewillbeplayed.com/Shirakawa/Y.html
- Page title: Shirakawa's Box Packing Collection : Y
- Last updated: Mar 21, 2015
- Summary: Extensive tiling and packing data for the Y-pentomino (5/3). The page declares 2D, 3D, and 4D as "Complete." It lists dozens of prime boxes across all dimensions with solution counts ranging from single digits to trillions (e.g., Y-90x12 has 21,482,915,860,930,403 solutions).

## Sections

- Pentomino (5/3)

  - 3D
  - 4D
