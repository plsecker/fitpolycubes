## 3. Encoding soundness summary (formal audit; full table in
`z_6x6x10_unsat_certification.md` §2)

The reduction `Z tiling exists ⟹ CNF satisfiable` is proven: a tiling is a
set of 72 pairwise-disjoint legal placements covering all 360 cells; the
placement set contains every legal placement (verified twice — against the
repository generator and, see §4, against published constructions); the
clauses are exactly "every cell covered" and "no overlaps", both satisfied by
any tiling. Hence a spurious UNSAT is impossible given the verified
placement set and a sound complete solver. Conversely, a satisfying
assignment is an exact cover by legal placements, i.e. a tiling.

## 4. Pipeline validation against published ground truth

The known-SAT gap identified in the earlier audit is **closed**. The
published solution page for the smallest known-SAT Z box
(`Pentominoes/Z-10x10x6.html` — the 6×10×10 prime, Shindo 1997 / ISHINO 2000)
embeds **four machine-readable tilings** (layer-wise character grids). All
four were parsed and validated independently (in-browser JS and Python,
including RM-orientation congruence, connectivity, exact cover): **4/4 valid,
480/480 published piece placements present in the audited placement set**.
Forcing the published tiling as SAT assumptions in the audited CNF returns
**SAT with exactly the published tiling** (extraction + geometric validation
✅). The one historical anomaly (the 0.4 s "SAT" on 10×10×6 with 93 garbage
pieces) was root-caused to a numpy int64 shift overflow in the *prototype*
generator (bits ≥ 63 wrap), fixed by int-casting, and is superseded — it is
not part of this package's evidence.
