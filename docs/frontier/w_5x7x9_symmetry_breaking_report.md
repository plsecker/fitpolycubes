## 1. Symmetry Group

### 1.1 Box-Preserving Symmetries

For a rectangular box with distinct dimensions (5, 7, 9), the full symmetry group is **D2h** with **8 elements**:

| # | Permutation | Signs | Description |
|---|-------------|-------|-------------|
| 1 | xyz | (+,+,+) | Identity |
| 2 | xyz | (+,-,-) | 180° rotation about x-axis |
| 3 | xyz | (-,+,-) | 180° rotation about y-axis |
| 4 | xyz | (-,-,+) | 180° rotation about z-axis |
| 5 | xyz | (-,+,+) | Reflection through yz-plane |
| 6 | xyz | (+,-,+) | Reflection through xz-plane |
| 7 | xyz | (+,+,-) | Reflection through xy-plane |
| 8 | xyz | (-,-,-) | Inversion |

**Key property:** Since all three dimensions are distinct, **no coordinate permutation** preserves the box. Only the identity permutation (xyz) is valid. The group is generated by three independent reflections.

### 1.2 Full Coordinate Group (48 elements)

The full coordinate group (6 permutations × 8 reflections = 48) includes coordinate permutations that change the box dimensions. For example, permuting (x,y,z) → (y,x,z) maps the 5×7×9 box to a 7×5×9 box. These transformations are **not symmetries of the original box** and cannot be used for symmetry breaking in the search.

However, the full 48-element group is useful for **canonicalizing solutions** after they are found. Under this group, the 6 root placements collapse to a single orbit, and the known solution has a 48-element orbit with trivial stabilizer.

## 2. Symmetry-Breaking Rule

### 2.1 Rule Definition

**Symmetry-breaking rule for rectangular boxes with distinct dimensions:**

1. Identify the canonical first cell: the cell with the fewest valid placements (typically a corner).
2. Generate all placements covering that cell.
3. Group them into orbits under the **8-element D2h box-preserving symmetry group**.
4. For each orbit, retain only the lexicographically smallest placement (the canonical representative).
5. Remove all non-canonical root placements from the solver's placement pool.

### 2.2 Completeness Proof

**Theorem:** Every valid tiling of the box is symmetry-equivalent to a tiling whose root placement (covering the canonical first cell) is one of the retained canonical representatives.

**Proof:**
- Let T be any valid tiling, and let p be the placement in T that covers the canonical first cell c₀.
- Let G be the 8-element D2h symmetry group of the box.
- Let O(p) = {g(p) : g ∈ G} be the orbit of p under G.
- Let p* = min(O(p)) be the canonical representative of this orbit (lexicographically smallest).
- There exists g ∈ G such that g(p) = p*.
- Apply g to the entire tiling T: T' = g(T).
- T' is a valid tiling (symmetries preserve validity).
- T' has p* as its root placement.
- Since p* is in the canonical set, T' is in the search space.
- Therefore, every tiling has a symmetry-equivalent tiling in the reduced search space. ∎

### 2.3 Implementation

The symmetry breaking is implemented in `common/polycube_utils.py` via the `generate_placements` function with `break_symmetry=True`. For rectangular boxes with distinct dimensions, the function:

1. Identifies all placements covering (0,0,0).
2. Groups them into D2h orbits.
3. Retains only canonical representatives.
4. Returns the filtered placement list.

The 8-element D2h group preserves the box dimensions but cannot map between different W orientations at the root. Each root placement uses a different W orientation (different set of vectors from (0,0,0)), and these orientations are symmetry-inequivalent under reflections alone.

## 6. Other Symmetry Opportunities

### 6.1 Later-Branch Symmetry

After placing the first piece (covering (0,0,0)), the remaining symmetries are those that fix that piece. Since all 6 root placements have no internal symmetry (trivial stabilizer under D2h), **no symmetries remain** after the first placement. Later-branch symmetry breaking is not applicable.

### 6.2 Connectivity Constraints

At depths 55-61, 73.9% of dead ends are connected (single component but untileable). These cannot be pruned by connectivity checks. The remaining 26.1% have disconnected components and could be pruned earlier, but this would only reduce the search by ~26% at deep depths, not at the root.

### 6.3 Z-Layer Ordering

Alternative cell ordering (by z-layer instead of MRV) was tested but also timed out. The MRV heuristic is already optimal for exact cover.

**Classification: C — Full enumeration is currently impractical without a substantially different algorithm.**

The symmetry breaking cannot reduce the search space for W 5×7×9 because all 6 root placements are symmetry-inequivalent. The search tree is large enough that the Python solver cannot complete within practical time limits, and the Numba solver also times out.

### 7.3 Recommended Next Steps

1. **Investigate Numba timeout** — The Numba solver works correctly on V 5×5×6 (1.8s) and V 5×5×9 (145s) but times out on W 5×7×9. Understanding why would help determine if a Numba-based exhaustive search is feasible.

2. **Use the known solution's orbit** — Generate all 8 symmetry-equivalent solutions from the known solution. If the published claim is "1+" (one or more), the known solution may be the only one up to symmetry.

3. **C++ solver** — The existing `solvers/solver.cpp` is hardcoded for piece N but demonstrates that a compiled C++ solver would be orders of magnitude faster. Porting the Algorithm X solver to C++ would make the W search feasible.

4. **SAT solver with symmetry breaking** — Encode the problem as SAT with explicit symmetry-breaking predicates. Modern SAT solvers (CaDiCaL, Kissat) can handle problems of this size.
