   ≥ 3652, verdict "V=45 PROVEN NEGATIVE") was generated by the unsound min‑id pre‑filter
   that excluded min‑id 3590, and was deleted. **The backup
   (`data/ck6_v45_buggy_backup_20260916_083816/`) does NOT contain the old corpus** — it
   holds empty new‑format stubs (minid_counts.json: 3,938 zero hist entries, total=0;
   shards.json: 4 empty shards; shard_001..003.json: empty results). `report.json` and
   `shard_000.json` were not backed up. The retired corpus survives only in git history (HEAD).
2. **Solver modified (working tree, uncommitted).** `solvers/t_ck6_oddity_v35_search.py`
   adds `count_minids_sqlite` (monolithic SQLite‑backed DFS count; deletes the DB on
   completion) and a `limits` dict in `run_shard` (40M states / 3600 s / 10,838 MiB) that is
   passed to `iter_targets_seeded` but **not enforced there** (dead code — only
   `iter_targets_seeded_seeds` enforces limits). `tools/frontier/test_placement_domain_completeness.py`
   is a docstring‑only change.
3. **Reconstruction artifacts are not a completed run.** `data/ck6_v45/frontier_reconstruction_*`
   were produced by `tools/full_scan_v45.py` scanning `visited_v45.db` (the count DB) read‑only.
   Manifest (08:58) records a 763.5 GB DB; checkpoint (11:12) shows **15,900,000 of ~60M masks
   processed**; the JSONL holds 14,256,611 "unfinished" records — **~90% of scanned masks** —
   which proves the DB was **live/incomplete** while scanned (children not yet written). The DB
   no longer exists. These artifacts do **not** confirm the 7,170,536 / 60,136,018 figures;
   those figures come from the refined run (item 4). `tools/reconstruct_v45_frontier.py` is
   broken (duplicated loop + module‑level IndentationError) and cannot run.
4. **The only complete piece‑V evidence is the pair (3590, 3591) partition.**
   `data/ck6_reuse/v45_v_3590_refined/` (commit 9a30587, 2026‑09‑13) is a complete run with
   root S = {3590, 3591}, base 3591, children 3592/3854/3855/3894/3895:
   7,170,536 targets / 60,136,018 states, 0 SAT, George B‑9 target present (min orbit 3590,
   centre‑adjacent [3652, 3937]), V‑piece does not tile it, repo‑M smoke = 12 covers.
   Caveats: the "expected" totals have **no provenance in the repo** (wrapper scripts in
   `/tmp/opencode/`, uncommitted), so the "exact match" validation is self‑referential; and
   `run.log` vs `final.json` disagree on George presence (run.log: present=false, min_orbit
   3036; final.json: present=true, min_orbit 3590).
5. **The complete/forked runs are stopped and incomplete.** `v45_v_3590_complete/` (commit
   3698eeb, 2026‑09‑13) partitioned min‑id 3590 into pair branches: 16 complete, 3598 partial,
   ~330 pending. `v45_v_3590_forked/` (2026‑09‑14, SIGINT) continued branch 3598; deep
   children hit the 10,838 MiB RSS limit and failed (b3598_c3894 DONE 28,198 targets;
   b3598_c3902 DONE 0 targets). Earlier attempts (`overnight_v45_3590`, `v45_desktop`,
   `v45_v_desktop`, `run2`, `run3`) were all stopped by RSS/RAM monitors or STOP files.
6. **Corrected pipeline is sound but unexercised at scale.** `solvers/ck6_sharding_corrected.py`

   min‑ids has been run with it. The monolithic count attempt (`visited_v45.db`) never produced
