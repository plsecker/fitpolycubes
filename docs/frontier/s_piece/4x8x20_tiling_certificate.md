# S 4x8x20 Tiling Certificate

The 128 S placements of the 4x8x20 tiling, reconstructed in ordinary (x, y, z) coordinates from the verified 20-layer frontier cycle (`docs/s_4x8x20_frontier_cycle.md`), together with the coverage and overlap checks.

## Source and coordinate conversion

Placements are taken from the verified cycle data (`/tmp/opencode/s_4x8x20_frontier_cycle_full.txt`, output of `/tmp/opencode/extract_20layer_path.py`).  The cycle reports each placement with z relative to the frontier layer 0 of the pre-shift state.  Layer k (k = 1..20) fills absolute layers k-1, k, k+1, so the absolute offset is k-1:

    (x, y, z_rel)  ->  (x, y, z_rel + k - 1)

Layer 20 (the final edge `WORD_MASK -> 0`) is an immediate shift with no placements, so all 128 placements lie in layers 1..19 and occupy absolute z in [0, 20).
