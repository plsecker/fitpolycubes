# Z-Frontier Symmetries: Canonicalization Safety

Analysis for `solvers/s_z_frontier_packed.py` (S in 4x8, 4 z-layers).
Authority: the complete placement set generated by
`common/polycube_utils.generate_placements(PENTACUBES["S"], (4, 8, 20),
break_symmetry=False)` (3944 placements), plus the reachable frontier
state space explored by the solver's first-empty-cell rule.

| Transform | Verdict | Evidence |
|---|---|---|
| identity | SAFE | Preserves the complete generated placement set and the explored frontier state space is trivially invariant under it. |
| left-right reflection | NOT SAFE | Does not preserve the placement set: S is chiral, so reflecting a placement produces a mirror-image placement that is not in the generated set. |
| top-bottom reflection | NOT SAFE | Does not preserve the placement set: S is chiral, so reflecting a placement produces a mirror-image placement that is not in the generated set. |
| 180-degree rotation | NOT SAFE | Preserves the placement set (it is the proper rotation Rz180), but the explored frontier state space is not invariant under it: the 180-rotation of a first-level state is a template covering cell 31, and no such template is reachable. |
